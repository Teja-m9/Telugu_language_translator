# Telugu Language Translator

This project is a **Telugu Language Translator** developed using the **Google Translate API** and deployed using the **Flask framework**. It allows users to translate text from any language into Telugu through a simple web interface.

## Features

- **Real-time Translation**: Translates text from any language into Telugu.
- **User-Friendly Interface**: Simple and interactive UI for translating text.
- **Powered by Google Translate API**: Uses the Google Translate API to provide accurate translations.
- **Flask Backend**: Flask web framework used to serve the application and handle requests.
- **Live Web Interface**: Access the translator from your web browser.

## Technologies Used

- **Flask**: A lightweight WSGI web application framework for Python used to handle HTTP requests.
- **Google Translate API**: An API provided by Google for translating text between different languages.
- **HTML/CSS**: For creating the user interface.
- **JavaScript (jQuery)**: For dynamic interactions and making AJAX requests to the backend.
